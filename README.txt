BICHOO ORNAMENTS WEBSITE — STARTER BUILD

This is a fresh, responsive static website for Bichoo Ornaments.

PREVIEW
1. Extract the ZIP.
2. Open index.html in Chrome.

PUBLISH
Recommended simple route:
1. Create a GitHub account (if you do not already have one).
2. Create a new public repository named bichoo-ornaments.
3. Upload all files and folders from this ZIP (keep assets/ as a folder).
4. On Render, create a new Static Site and connect the repository.
5. Build command: leave blank.
6. Publish directory: .
7. Deploy.

CUSTOM DOMAIN
After deployment, add bichooornaments.com in Render's custom domains and follow Render's DNS instructions at your domain registrar. Do not share passwords or OTPs.

IMPORTANT
- Owner portrait areas are temporary placeholders; add photographs later.
- Collection art is temporary placeholder artwork; actual jewellery photos can be added later.
- This first version is a catalogue and WhatsApp enquiry website, not an online payment/checkout store.
- Business details are based on information supplied by the owner. Please verify all details before public launch.
- Before launch, confirm the domain is available and purchased.
- To change the WhatsApp number, search the files for 917006692083.
- Main content is in index.html; visual styling is in styles.css.
